### ✨ 核心亮点

* 🤖 **Multi-Agent 协同路由**：基于 Supervisor 智能体，自动分发任务至路书 Agent、算账 Agent 与装备清单 Agent。
* 📚 **RAG 深度攻略召回**：基于 LlamaIndex 检索引擎，结合私有 Markdown/PDF 深度游与自驾路书，拒绝大模型“幻觉”。
* 🧭 **多交通方式编排**：无缝支持高铁、自驾（新能源/燃油）、飞机与公共交通等多种出行组合。
* 📊 **结构化行程与交互编辑**：摒弃纯文本对话框，将 AI 生成的决策实时解析为结构化数据，支持前端拖拽重排与节点 CRUD。
* 💰 **动态预算与足迹看板**：AI 预估油耗/路费/门票，生成交互式记账账本与行前物品 Checklist。
